## Exigências técnicas e sugestões

Para a opção web, o manual classifica HTML5, CSS3 (com menção a Bootstrap/SASS)
e JavaScript/TypeScript como obrigatórios. O DINNOS utiliza HTML5, CSS3 e
TypeScript. O recorte não explicita se Bootstrap ou SASS é adicionalmente exigido;
registrar o CSS autoral utilizado e confirmar essa interpretação com a instituição
se necessário. Não declarar uso dessas ferramentas, pois não estão no projeto.

React/Angular/Vue, banco de dados, Node.js/Express ou similares e consumo de APIs
REST são classificados como opcionais. C# e Windows Forms/WPF pertencem à opção
desktop, que não foi escolhida. Node.js é utilizado no desenvolvimento e nos testes;
não existe servidor próprio em Express na solução publicada.

Fluxograma, relacionamento entre tabelas, Figma e link de repositório são sugestões
do trecho. Um link não substitui o tutorial e a descrição das telas exigidos.
